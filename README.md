# Superstore-Sales-Analysis
This project performs complete data analysis on a Superstore Sales dataset using Python.

## Project Includes
- Data cleaning and preprocessing
- Feature engineering
- Exploratory Data Analysis (EDA)
- Data visualization using Matplotlib & Seaborn
- Business insights and recommendations

## Files
- `Superstore_Sales_Analysis.ipynb` – Jupyter Notebook with full analysis
- `Superstore_Sales_5000.csv` – Sales dataset

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Objective
To analyze sales performance, profit, customer behavior, and trends to support business decision-making.
